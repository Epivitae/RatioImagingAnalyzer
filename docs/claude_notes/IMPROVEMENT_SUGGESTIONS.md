# RIA 改进建议

## 已修复的 Bug (2024-01-06)

### 1. ROI Plot Curve 无法弹出窗口
- **位置**: `gui_components.py:622-625`
- **问题**: `_generate_mask()` 方法使用 `shape[1]` 和 `shape[2]` 获取图像尺寸，但数据格式已改为 5D `(T, C, Z, Y, X)`，导致取到的是 C 和 Z 维度而不是 Y 和 X。
- **修复**: 改用 `shape[-2]` 和 `shape[-1]` 获取正确的 Y 和 X 维度。

```python
# 修复前 (错误)
h, w = self.app.data1.shape[1], self.app.data1.shape[2]

# 修复后 (正确)
h, w = self.app.data1.shape[-2], self.app.data1.shape[-1]
```

## 代码质量改进建议

### 1. 减少调试打印
- `model.py` 中的 `get_processed_frame()` 方法包含大量 `print()` 语句用于调试
- 建议：使用 Python `logging` 模块，设置不同的日志级别 (DEBUG, INFO, WARNING)
- 这样可以通过命令行参数 `--debug` 控制是否显示详细输出

### 2. 类型注解完善
- 代码中部分函数缺少类型注解
- 建议：为关键公共 API 添加类型注解，方便 IDE 自动补全和静态检查

### 3. 单元测试覆盖
- 当前只有 E2E 测试 (`auto_drive.py`)
- 建议：为 `processing.py` 和 `io_utils.py` 中的核心函数添加单元测试
- 特别是 `process_frame_ratio()`, `calculate_background()`, `split_channels()` 等

## 功能增强建议

### 1. 批量处理模式
- 当前只能单文件处理
- 可以考虑添加批量导入多个文件并自动生成报告的功能

### 2. 预设管理
- 保存常用的参数配置 (阈值、平滑度、颜色映射等) 为预设
- 方便快速应用到不同实验

### 3. 更多导出格式
- 当前只支持 TIFF 导出
- 可以添加 CSV 导出 (用于统计软件)
- 可以添加 MP4/GIF 导出 (用于展示)

### 4. ROI 模板
- 保存 ROI 模板，可以应用到相似结构的其他图像
- 支持 ROI 的批量编辑 (缩放、移动)

### 5. 实时预览优化
- 当前每次调整参数都会重新计算整帧
- 可以考虑对大图像使用降采样预览，确认后再全分辨率处理

---

## 性能优化建议

### 1. 多线程并行计算
- ROI 曲线计算可以使用 `concurrent.futures.ThreadPoolExecutor` 并行处理多个 ROI
- 对于大文件，可以并行计算多个帧的处理结果

### 2. GPU 加速 (可选)
- 对于需要处理大量数据的用户，可以考虑使用 CuPy 或 CUDA 加速
- 但这会增加依赖复杂度，建议作为可选功能

### 3. 内存映射
- 对于超大文件 (>4GB)，可以使用 `numpy.memmap` 或 `zarr` 进行内存映射
- 避免一次性加载全部数据到内存

## 代码架构改进

### 1. 事件系统
- 当前 UI 和数据层耦合较紧
- 可以引入简单的事件总线，解耦组件间通信

### 2. 配置文件
- 将默认参数、颜色主题等抽取到 YAML/JSON 配置文件
- 方便用户自定义

### 3. 插件系统 (长期)
- 允许用户编写自定义处理算法
- 通过插件形式加载，不修改核心代码
